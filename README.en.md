# GEOrank

**GEOrank** is an open-source **GEO / content-engineering workbench** (**GEO Suite**): diagnose → knowledge base → keyword/prompt expand → distribute (GEOFlow) → trust observation → configure.

It is **not** the legacy Q&A / action-plan portal, company directory, or expert channel.

- **Primary path**: local Suite — `http://localhost:3009/suite`
- **Start (Rank + Flow)**: `.\scripts\start-geo-suite.ps1`  
  Ports (typical): Rank UI `3009`, API `8000`, GEOFlow `18080`
- **Docs**: [docs/README.md](docs/README.md) · [geo-suite.md](docs/geo-suite.md) · [content-engineering-sop.md](docs/content-engineering-sop.md) · [cn-product-demo-v2 (DJI Mini 5 Pro)](docs/pilot-demo/cn-product-demo-v2/)
- **Caveat**: diagnostic “citation / endorsement readiness” ≠ AI answer citation rate; trust observation = **API sampling**, not web scraping.

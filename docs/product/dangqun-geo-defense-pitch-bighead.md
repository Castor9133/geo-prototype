# 党建党媒 GEO 答辩话术（Big Head 版）

> 用途：答辩演示开场 + 过场 + 收束。语气偏「战略叙事」，少技术词。  
> 时长建议：**开场 90 秒 → 演示 6–8 分钟 → 收束 60 秒**。  
> 日期：2026-08-05

---

## 一、开场 90 秒（先打动，再讲系统）

各位领导好。

今天不讲功能清单，先讲一件事：

**老百姓问问题的方式变了。**  
以前搜网页、刷公众号；现在很多人直接问豆包、元宝、DeepSeek——**答案引擎正在变成新的「第一信息入口」。**

这对党媒意味着什么？

不是「多发几篇稿」这么简单，而是：  
**当群众问到与我们相关的话题时，AI 提不提我们、引不引我们、说得准不准。**

提不到——等于在新入口失声。  
提了但乱说——等于口径失控。  
做了很多却说不清有没有用——等于资源打水漂。

所以我们做的不是又一个「内容后台」，而是：

> **让编辑部能像经营选题一样，经营「AI 会不会说到我们、说得对不对」——并且用证据说话。**

作业单元不是篇数，是**一条可验收的选题策略**：  
查清现状 → 定策略 → 备口径与稿件 → 投放 → 复测 → 判定有没有见效。

---

## 二、三句「领导最爱听」的定位（可反复用）

1. **我们管的是「AI 里的话语权」，不是发文 KPI。**  
2. **闭环到判定：做没做完、有没有效，系统能卡住，不靠口头。**  
3. **诚实比漂亮更重要：没测过就写「未测」，绝不拿演示数当战果。**

第三句是答辩「信任锚」。Big Head 最怕被 PPT 忽悠；你主动说清边界，反而加分。

## 三、演示串场话术（对着屏幕说）

### 1）工作台 / 选题（30 秒）

「这是编辑的日常入口。  
不是让编辑去学一堆 AI 黑话，而是：**今天哪条选题在推进、下一步该干什么**——系统会指出来。」

### 2）查页面 + 建题（40 秒）

「先回答一个很朴素的问题：我们的页面，AI 抓不抓得到、结构齐不齐。  
查完一键进选题——**从发现问题到开工，不断档。**」

### 3）定策与硬拦门（45 秒）

「定策要补齐：写什么、用哪几句用户问法、发到哪、怎样算有效。  
关键一步缺了——按钮就是灰的。  
**不是刁难编辑，是对领导负责：没摸底、没问法，不许假装已经开工。**  
特殊情况管理员可写理由强开——留痕，不留空子。」

### 4）知识与写稿体检（50 秒）

「稿不是随便写。口径在知识库里，写完要过体检。  
绝对化空话、对不上口径的数字——红牌，过不了审。  
**我们怕的不是写得少，是写歪了、写飘了。**」

### 5）观测与答题卡（60 秒）——本轮最「可摸」的亮点

「投放前摸底、投放后复测——用约定账号真实去问。  
系统不替你编答案；编辑把结果登回来。  
不会用表格的，也能下载答题卡填完再传回来。  

每一条还能盖章：完全没提、竞品抢戏、提了但靠后、疑似说坏话——  
**选题池立刻知道先打哪一仗。**」

### 6）判定与迭代（40 秒）

「复测够了才能判定：见效 / 部分见效 / 未见效。  
见效的沉淀进库；不够的开新一版。  
**篇数可以很多，但验收只认策略有没有闭环。**」

### 7）演示开关（20 秒，必须说）

「今天是答辩演示，界面上会看到演示标——那是方法演示，不是全网引用率。  
真正上线，开关一关：**没样本就是『未测』，漂亮假数进不来。**  
这是我们对事业负责的底线。」

## 四、若被追问：三句「诚实加分」

| 领导可能问 | 建议答法 |
|------------|----------|
| 引用率提高了多少？ | 「我们测的是约定账号上的点名结果，能回答『这条策略有没有见效』，**不等于全网引用率**。全网是下一阶段的测量工程。」 |
| 和市面 GEO 工具比？ | 「多数是监测仪表盘。我们是**实施平台**：策略、口径、写稿、观测、判定绑在一起，还带编辑部角色闸门。」 |
| 编辑愿不愿意用？ | 「步骤按编辑语言写；拦门拦的是『假完成』；答题卡降低门槛。先跑通 6 条策略闭环，再谈规模。」 |

---

## 五、收束 60 秒（要留下一句「可拍板」的话）

各位领导，总结一句：

**当 AI 成为新入口，党媒不能只赢在发稿量，要赢在「被正确提及」。**

今天演示的，是一套可落地的编辑部作业：  
**选题即策略、证据即验收、口径有体检、未测不编数。**

请领导支持的不是「再做一个系统」，而是：

> **把「AI 话语权」当成和选题、审稿同级的日常能力——我们用工程把它管起来，用证据把它验起来。**

谢谢各位领导。

## 六、上台备忘（别念技术词）

| 别说 | 改说 |
|------|------|
| handoff / API / lint | 交接检查 / 回传结果 / 写稿体检 |
| baseline / after | 投放前摸底 / 投放后复测 |
| GEORANK_DEMO_METRICS | 演示开关；上线关掉，未测不编数 |
| 六元组 | 写什么、问什么、发哪、怎样算有效 |

**情绪节奏**：危机感（入口变了）→ 使命感（话语权）→ 可靠感（硬拦门+诚实）→ 行动感（请支持把能力做进日常）。

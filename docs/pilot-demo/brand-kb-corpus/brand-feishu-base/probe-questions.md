# 探针题 · 飞书多维表格（可信观测 / 验证）

用于答案引擎抽样、人工核对与 Suite「可信观测」演示。  
期望答案须能回到 `fact-cards` 对应 ID；**不以「是否被模型引用」作为本文件验收标准**。

| ID | 中文问题 | 期望事实卡 | 题型 |

## 抽样建议

1. 每轮至少抽 Q1 + 任意 2 道参数题（Q4–Q8）+ 1 道场景/权限题  
2. 核对口径：数字必须与帮助中心一致；若官方已更新，以官方为准并回写事实卡  
3. 记录「正确提及 / 错误提及 / 未覆盖」，勿把页面诊断分当成引用率  
4. 内容工程口径：区分 **mention**（出现品牌）与 **citation**（引用可核来源/目标页）；吸收句应能回到事实卡或答案摘要块

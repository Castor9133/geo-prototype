# 深圳广电 × 第一现场 · 拓词知识工程示范包

> **演示样例** · 仅含公开可核的身份/隶属/别名/选题角度/禁语/竞品对标。  
> **禁止**编造收视率、「全国第一」或暗示已实测大模型引用率。

本包用于向业务说明：**备什么样的知识库与知识卡片、如何切片、拓词选库后会怎样变聪明。**

## 业务要准备什么

| 层级 | 备什么 | 不备什么 |
|------|--------|----------|
| **事实卡（必须）** | 身份、隶属、别名、选题角度、禁语、竞品 | 口号堆砌、无出处数字 |
| **故事正文（建议）** | 1～2 篇可引用的融媒/民生说明（L2） | 把所有卡片粘成一篇再指望切片「猜」关系 |
| **切片** | 长文才切；卡片进 `fact_cards` JSON | 把关系句塞进超长文中间被切断 |

详见 [CARD_CHECKLIST.md](./CARD_CHECKLIST.md)。导入步骤见 [import.md](./import.md)。

## 卡片 ≠ 长文

- **卡片**：结构化字段（`card_type` / `entity_name` / `relation` / `claim`…），拓词时优先读，用来定「谁是谁、谁隶属谁、谁是竞品」。
- **长文**：给人读、给 RAG 检索场景语境；系统按约 **800 字**（双换行优先）切片。
- **原则**：关系与口径靠卡片；证据与故事靠正文切片。

# L3 模型可读内容清单（图文样板 · 非视频管线）

本轮原型只交付 **C1**：1 条合成图文 + 文字稿/元数据。不做真视频上传/转写/剪辑。

## 人共鸣

- [ ] 开场是真实问题，不是口号堆砌
- [ ] 有清晰叙事弧（问题→是谁→怎么做→边界）
- [ ] 禁用硬广式「保证上榜」表述

## 模型可读

- [ ] 规范实体名前后一致（本样板：GEO 示范栏目）
- [ ] 章节标题可被拆段（H2）
- [ ] 事实锚点指向 L2 事实卡 ID
- [ ] 口述要点文字稿可对齐字幕/摘要
- [ ] 官方入口与禁用表述可抽取

## 与 L2 关系

- L2 提供证据骨架；L3 提供信任与叙事血肉
- 无事实卡支撑的漂亮文案，不进入「信任素材」步

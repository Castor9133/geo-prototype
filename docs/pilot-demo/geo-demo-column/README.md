# GEO 示范栏目（合成演示资产）

运行时文件在前台静态目录：[`/pilot-demo/geo-demo-column/`](../../../dist/pilot-demo/geo-demo-column/)。

| 文件 | 用途 |
|------|------|
| `metrics.json` | Suite「事实卡」步覆盖率/向量化率看板 |
| `trust-asset.html` | L3 模型可读图文样板 |
| `measure-demo.json` | 可信观测尚无真实 run 时的回落展示 |
| `fact-cards.md` | 可导入 GEOFlow 知识库的事实卡正文 |
| `l3-readable-content-checklist.md` | L3 规范清单（非视频管线） |
| `import-to-geoflow.md` | 灌入 Flow KB 的操作步骤 |
| `../../../scripts/import-geo-demo-factcards.ps1` | 打开 Flow KB + 事实卡文件的本机助手脚本 |

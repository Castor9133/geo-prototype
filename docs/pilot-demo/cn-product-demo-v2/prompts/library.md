## P01 · 七段式产品说明（结论前置）

```
你是品牌内容编辑。仅依据【知识库/事实卡】撰写「DJI Mini 5 Pro」产品说明，全中文。

2) 核心能力分层（影像 / 飞行续航 / 避障 / 图传 / 云台）
3) 关键参数（只写知识库有数字的项，文字罗列，勿用 Markdown 表）

5) FAQ（3 问：重量、续航、是否防水；格式「问：」「答：」）
6) 边界（实验室测得、SRRC vs FCC、避障光照条件、不防水）
7) 行动建议（查阅官网 specs/FAQ，不强迫成交）
排版：禁止 **加粗**、# 标题、--- 分隔线、反引号；像已排版正文。
约束：禁止「全球第一」「保证被全部大模型引用」；无证据数字写「未在资料中找到」。
```

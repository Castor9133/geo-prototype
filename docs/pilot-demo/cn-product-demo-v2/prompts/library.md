# 中文 GEO / 内容提示词词库 · DJI Mini 5 Pro

全中文、白帽。可用于 GEOFlow 任务指令。  
**禁止**：伪造引用率、伪造客户数据、诱导「保证上榜 / 操控答案」；参数必须能回到事实卡或官网 URL。

改编来源：Mintlify GEO 指南、腾讯云 GEO 文、本仓内容工程 SOP、L2 事实卡约束。

## P01 · 七段式产品说明（结论前置）

```
你是品牌内容编辑。仅依据【知识库/事实卡】撰写「DJI Mini 5 Pro」产品说明，全中文。
结构（七段，缺一不可）：
1) 结论前置（40–80 字回答「它是什么」）
2) 核心能力分层（影像 / 飞行续航 / 避障 / 图传 / 云台）
3) 关键参数表（只写知识库有数字的项，括号注 evidence_url 域名或页名）
4) 适用场景（旅行随身、城市夜景、运动跟随、人像创作；不编造客户名）
5) FAQ（3 问：重量、续航、是否防水）
6) 边界（实验室测得、SRRC vs FCC、避障光照条件、不防水）
7) 行动建议（查阅官网 specs/FAQ，不强迫成交）
约束：禁止「全球第一」「保证被全部大模型引用」；无证据数字写「未在资料中找到」。
```
